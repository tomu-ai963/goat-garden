# 🐐 やぎさん牧場 〜しあわせホルモン農園〜

ブラウザでそのまま開いて遊べる、ポップでアニメ風の2D牧場＆ヤギ追い込みゲームです。
外部画像や重いライブラリは一切不要で、HTML/CSS/JavaScript のみで動作します。PCのマウス操作とスマートフォンのタップ＆スワイプ両方に完全対応しています。

---

## 🎮 すぐに遊ぶ方法（起動手順）

以下のいずれかの方法ですぐにブラウザで開いて遊ぶことができます。

### 方法1：ファイルを直接ブラウザで開く（一番簡単！）
- `goat-garden` フォルダ内の `index.html` をダブルクリック、または Chrome / Edge / Safari 等のブラウザにドラッグ＆ドロップしてください。
- Windows の PowerShell から以下のコマンドでも一発で起動できます：
  ```powershell
  Start-Process index.html
  ```

### 方法2：ローカルHTTPサーバーで起動する
Node.js や Python がインストールされている場合、以下のコマンドで起動してブラウザから `http://localhost:8000` にアクセスできます：

- **Python の場合**:
  ```bash
  python -m http.server 8000
  ```
- **Node.js (npx) の場合**:
  ```bash
  npx serve .
  ```

## 🌟 ゲームのルール＆システム

### 2つの幸福ホルモンポイント
1. **🌱 セロトニンポイント（畑で獲得）**
   - 畑の空き区画をタップして種まき、育った作物をタップ（またはなぞる）で収穫！
   - ショップで新しい作物の種、畑の拡張、柵の補強、便利アイテムの購入に使用します。
2. **💖 オキシトシンポイント（ヤギとの絆で獲得）**
   - 脱走したヤギを手でやさしく柵へ戻すのがいちばん多く増える（+12）。なでる（+1、3回でまんぞく）、牧草や餌をあげるでも少し増加。
   - 信頼度（Lv.1〜10）が上がると、脱走頻度が下がり、逃げたときも柵へ誘導しやすくなります。
   - ポイントを貯めると、2匹目・3匹目…最大5匹の個性豊かなヤギ（メイ、ユキ、モカ、ココ、ラテ）をお迎えできます。

## 🐐 ヤギの脱走と追い込み（重要）

ヤギはときどき柵をピョーンと飛び越えて脱走し（ゲートが閉まっていても柵のどこからでも出られる）、畑の作物をめがけて歩いていきます。
作物を食べられると作物が消えてセロトニンが少し減ってしまいますが、食べたヤギは満足してハートを出し、オキシトシンが少し増えます（「憎めない」演出）。

### 追い込み＆誘導ツール
- **👆 おまかせ（基本の手）**
  - タップした場所で動作が自動で切り替わります：畑 → 種まき・収穫／柵の中のヤギ → なでる／脱走ヤギの近く → 追い込み。
  - 脱走ヤギの近くをクリック/タップすると、ポンッと波紋エフェクトが出て、ヤギが反対方向（柵の方）へトコトコ逃げます。
  - **ゲートはタップで開け閉め**。ふだんは閉まっていて、閉じたままだとヤギはゲートの前で止まってしまう。開けてから追い込み、全員戻ったらタップで閉めよう（開けっぱなしだと柵の中のヤギがゲートから出ていきやすくなる）。
  - ゲートを開けるとピンクの点滅矢印が出る。そこへうまく誘導すると中へ戻り、オキシトシンがたっぷり（+12）もらえます。
  - ゲートへの自動の吸い寄せは弱めなので、「ヤギとゲートを結ぶ線の反対側」を押すのがコツ。
  - ⚡ 脱走から8秒以内に戻すと +6、16秒以内なら +3 のスピードボーナス。
  - 🎉 5秒以内に続けて戻すと連続ボーナス（2匹目 +5、3匹目 +10 …）。

### 脱走のリスク
- 食べられた畑は 20 秒間「荒れた畑」になり、種をまけません。
- 外にヤギがいる間は、柵の中のヤギもソワソワして脱走しやすくなります（外の1匹ごとに脱走タイマーが1.6倍速）。
- **🪵 木の棒（ショップで解放）**
  - 近くで使うとヤギが「！」を出してビックリし、2倍の猛スピードで一気に柵へ逃げ帰ります。
  - 戻すのはとても簡単ですが、ヤギが拗ねてムスッ💢とし、オキシトシンポイントが減少します（次の脱走率も少し上がります）。
- **🥣 美味しい餌**
  - 脱走ヤギの近くで使うと、ハートを出して自分から嬉しそうに柵へ戻ってきます。オキシトシンもアップ！
  - 柵の中にいるヤギにあげると、美味しそうに食べて信頼度が一気に上がります。
- **🔔 鈴（ショップで解放）**
  - チリリン♪と鳴らすと、脱走している全ヤギが自分からおうちへ戻ってきます（クールダウンあり）。

## ⌨️ 便利なショートカット（PC）
- **1 〜 4 キー**：ツールの素早い切り替え（おまかせ / 木の棒 / 餌 / 鈴）
- **スペースキー**：ゲームスピード切り替え（1x のんびり ⇄ 2x サクサク）
- **S キー**：ショップの開閉
- **Esc キー**：モーダルを閉じる

進行状況はブラウザの `localStorage` に自動保存されます（5秒ごと＋ページを離れるとき）。
閉じている間は牧場の時間が止まり、作物の成長も脱走も進みません。脱走中のヤギは、再開すると脱走したままの場所から続きます。
いつでも気軽に遊んで、ヤギたちとの牧場生活を楽しんでください！
